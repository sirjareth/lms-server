# Activity: Hello World

## Objective

Students will gain hands-on experience setting up the basic structure of a Java program, defining a `public class` and `main` method, and printing text to the console using `System.out.println()`.

## Instructions

1. **Setup**
   - In your IDE, create a new Java class and name it `HelloWorld_Activity`.

2. **Create the `main` Method**
   - Inside the `HelloWorld_Activity` class, declare the standard Java `main` method (`public static void main(String[] args)`).

3. **Display the Output**
   - Inside the `main` method, use `System.out.println()` to print `"Hello, World!"` to the console.

4. **Save and Run**
   - Save your work and run the program in your IDE to verify that `"Hello, World!"` appears in the console without any syntax or runtime errors.

5. **Version Control and Submission**
   - **Git Workflow Reminder:** Before submitting, make sure your local changes are properly uploaded to your remote repository by following the standard Git process (`git add`, `git commit`, and `git push`).
   - Submit the **main GitHub repository URL** (e.g., `https://github.com/username/repository-name`) to our Google Classroom.
